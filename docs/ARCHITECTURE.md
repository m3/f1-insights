# System Architecture (`f1-insights`)

## Overview
`f1-insights` is built as a two-tier application managed via **PM2**:
1. **Data Analytics Pipeline (Python)**: Ingests raw telemetry and historical data from TracingInsights GitHub repositories and Jolpica/Ergast F1 APIs, calculates race pace deltas, tyre degradation models, and driver penalty points, and exports structured JSON feeds.
2. **Web Portal Dashboard (React + Vite)**: High-performance, dark-mode web application presenting pre-race previews, post-race debriefs, corner telemetry traces, penalty watches, and standings.

---

## Process Management (PM2)

PM2 controls both services as defined in [`ecosystem.config.js`](../ecosystem.config.js):

```
                       ┌─────────────────────────┐
                       │     PM2 PROCESS MGR     │
                       └────────────┬────────────┘
                                    │
           ┌────────────────────────┴────────────────────────┐
           ▼                                                 ▼
┌─────────────────────┐                           ┌─────────────────────┐
│  f1-insights-portal │                           │ f1-insights-pipeline│
│  (React / Vite SPA) │                           │  (Python Data Engine│
│  Port: 3000         │                           │   Cron: Every 6h)   │
└─────────────────────┘                           └─────────────────────┘
```

### PM2 Commands
- **Start All Services**: `npm run pm2:start`
- **Stop All Services**: `npm run pm2:stop`
- **Restart Services**: `npm run pm2:restart`
- **View Live Logs**: `npm run pm2:logs`
